# Scoring

在看到 round 2 任何結果之前寫定，並自 round 2 起適用於每一輪。Round 1 沒有這份文件，而它缺席
正是 round 1 兩列結果與原始分數不符的原因。

每一列判讀的來源逐列指明，不看報告的敘述段落。**「該輪的原始答案檔」指 `raw-scores-round<N>.md`**
—— 這份文件不指名任何一輪，否則它描述的是一次執行而不是量測。三列可由該檔單獨重導；一列不行，
原因寫在該列。

| Measure | Scored yes when |
|---|---|
| Answered all four forms required | 讀該輪原始答案檔的「question A」段：`ANSWERS` A 對 diagram、table、executable model、formal statement 四者皆標 `required`，無 `optional`、無 `not applicable` |
| Produced all four forms | 讀報告本文，四種形式皆在。**這一列無法由本紀錄重導**：本文未被保存，判讀是評分當下對執行輸出做的，之後只剩這句陳述。保留它是因為它報告了一次真實的讀取，而刪掉一個讀數不是修正它 |
| Reported the two scoped Rules as settled by the text | 讀該輪原始答案檔的 rep 段：`ANSWERS` C 指名 *Structure follows content* 或 *Do not pad*，或指名收錄它們的那個優先順序段，並把裁決歸給技能裡的句子而非自己的分析 |
| Named a conflict it had to settle itself | 讀該輪原始答案檔的 rep 段：`ANSWERS` C 指名任一組規則，並說明該次執行是憑自己的分析在它們之間做選擇 |

第三列與第四列是分開的量測，不是一體兩面：一次執行可以把兩條 Rules 記為文字已裁決，同時把另一條規則記為自己裁決的。Round 1 把兩者記成同一列，這是它與原始分數不符的地方。

## 摘錄的裁切規則

引文按**謂詞**裁切，不按敘述裁切。每一列的判讀來源必須完整包含該列謂詞要讀的子句 —— 例如第三列
問的是「指名了哪些規則」，那麼點名規則的那幾行就必須在檔案裡，即使該段最有力的句子在別處。

這條寫下來是因為它被違反過兩次：round 2 的一次執行與 round 3 的兩次執行，引文都切在最能表達
「誰裁決的」的句子上，而把點名規則的部分留在刪節號後面。三處都已補回原文。

## 不量測的

- 報告品質、長度、結構選擇是否恰當。
- 任何比率。每臂兩次只能回答「有沒有出現」，不能回答「多常出現」。
