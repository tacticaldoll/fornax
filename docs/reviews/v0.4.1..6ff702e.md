### Security Triage Alert

`distribution_manifest.validate_install_pins` interpolates two pieces of file-controlled text into
a printed `FAIL` line without `diagnostic_text.printable`, one line below a call that wraps. Both
attacks `printable` exists to stop are reachable, and both were reproduced:

- **Report forgery.** `RELEASE_REF` admits U+202E RIGHT-TO-LEFT OVERRIDE. A README pinned to
  `git+…@v0.9.9<RLO>1.4.0v` renders its own failure line as
  `install ref v0.9.9v0.4.1 must be v0.4.1` — a stale pin whose diagnostic reads as agreement.
- **No report at all.** A tracked file whose name is not valid UTF-8 reaches `relative_path` as a
  lone surrogate from `os.fsdecode`. Probed in a scratch worktree:
  `UnicodeEncodeError: 'utf-8' codec can't encode character '\udcff'` — the distribution check ends
  in a traceback instead of a diagnostic.

`diagnostic_text`'s own docstring names the second outcome exactly.

### Structural Appendix

`distribution_manifest.install_refs` — pure, no I/O. The `ends` set is asymmetric by design, which
is the repair the previous round closed as `QUOTE-CLOSER-BY-EXISTENCE`; confirmed holding under the
whitespace falsifier. The residual risk is not in the boundary logic but in what happens after it.

`check_citations.Modules` / `Symbols` — `Modules` is mutable by intent, a per-run parse cache
threaded as a parameter rather than a global. `Symbols` enforces its paired-optional invariant and
gates both accessors behind one reason. `citable`'s `symbols is not None` branch is unreachable for
a key taken from that map; not reported, it reads as deliberate.

`evidence_currency.load` — every unrecognised line raises rather than being skipped, which is what
made `EVIDENCE-SECTION-UNBOUNDED` closed rather than merely repaired. Its `FAIL` diagnostics print
to stdout while `main`'s registry failures print to stderr; not reported, because nothing captures
either today and the repo-wide convention is already mixed.

`runtime_contract.workflow_pins` / `run_commands` / `_installs` — the deepest new call chain, with
PyYAML, `shlex` and `packaging` each owning a grammar and hand-written structure between them.
`development-knowns.yaml` registers that residue accurately. Not gate-reviewed past Gate 5.
