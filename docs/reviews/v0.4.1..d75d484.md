### Structural Appendix

`record_shape.py` — three-level structure: `Seat`/`Subject` declare, `rules_for` derives discipline from subject, `Rule` subclasses judge one table. `Subject` is genuinely load-bearing. The design premise is that the contract's shape is derived, never copied (`declared`, `verdict_grammar`); the docstrings then copy its cardinality, which is where findings 5 and 7 in Structural Causes sit. `Rule.defects` yields strings so a rule cannot learn its file — clean. `main` re-globs `RECORDS` after `check` already did.

`check_citations.py` — read/judge split is clean (`prose` reads, `_line_citations`/`_symbol_citations` judge). `Modules.read` memoises parses; `citable` derives the external name set from imports rather than asking `find_spec`, which is the right call. The one silent path is the subject set itself.

`read_whole.py` — the type does the work: `Whole.__post_init__` enforces full-span in the constructor, so the invariant holds for any construction path, and `Read = Whole | Unread` admits no third answer. This is the strongest unit in the range.
