### Structural Appendix

**`agent_skill_format` package** — 十三個模組。`__init__` 的宣稱在**匯入層現已完全成立**：實測 package 內無任何 repo 側匯入，正向邊只有 `skill_model → schema`，反向環已消除。殘留的是散文層：`read_whole` 的 `COMMENT` 註解與新搬入的 `Line` docstring 各指名一次 repo 側的 `runtime_contract`，抽出後會懸空；沒有 gate 讀 docstring，故不構成 finding，但屬 carve-out 的 reach。

**`read_whole.Line`** — frozen dataclass，一個欄位，`__post_init__` 以 `ValueError` 帶原文拒絕含換行的文字。搬入後 `read_whole` 是唯一持有它的地方，但 `shell_script` 重新匯出，四個既有讀者仍走舊名。

**`schema.FormatSchema`** — 不可寫性現在是型別的性質：實測移除 wrap 恰 2 紅，`replace()` 產出的 schema 一樣拋 `TypeError`。wrap 只覆蓋 `families`，型別層沒有任何句子說這個保證涵蓋哪些欄位，日後加入一個可變欄位不會有訊號。

**`validate_skills.validate_skill`** — 四個參數全部必填。實測還原 3b 全綠——這個修復沒有、也不可能有 guard，因為測試側的 `check()` 仍帶著同一個預設。

**`test_module_claims`** — `LOCAL` 從「頂層 + package」擴大為 `scripts/` 全樹，claim 掃描以 `path.parent.name != "tests"` 明確收回範圍。新的邊界斷言覆蓋 package 頂層目錄；`ast.walk` 確實會下探 `TYPE_CHECKING` 區塊（實測轉紅），但 `PACKAGE_MODULES` 不遞迴。

**`docs/guards.md`** — 本 range 六次編輯。修好的：標題與導言、一處行尾空白、兩次類別座標重新指向、一列讀數的污染更正。新造的：量測段落切斷表格並讓三列 guard 掉出表格；該段落落在寫著「nothing measured」的標題底下；一列既決讀數被就地改寫；頭號 cause 的 guard 列仍寫著「no repair has landed」；一列預測與同檔另一列的現值互相牴觸；`TRAILING-WHITESPACE-IN-GUARDS` 的 re-runnable reading 實跑報 115 個檔案。
