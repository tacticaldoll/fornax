## Pattern

Causes 3, 5, 6 and 10 share one shape: **a unit's prose states the property intended and its code
implements a narrower one, and the gap is invisible because the narrow reading returns a
well-formed answer.** The fence pattern returned a shorter shape, the quoted ref returned a valid
release, text hygiene returned no diagnostic, and the ledger table returned a comparable column.
Nothing was raised in any of them.

The pattern-level repair this round adds is not another check. It is that a claim about a boundary
is verified by feeding the boundary something that crosses it — a nested fence, a space inside the
quotes, a NUL in a `.py`, a column from another round — and that this is done when the prose is
written, not when a review asks. Causes 4, 7 and 8 are the second shape: **a hand-kept inventory of
the tree, which under-reports and cannot be checked**, and the answer there was to name the
enumeration that re-measures it rather than to add the check that maintains it.
