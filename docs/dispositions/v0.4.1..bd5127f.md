## Pattern

produces a finding per round and prevents nothing, and each round's repair commit violates it
again** — which is the same weighing the repository already applies to checks, arriving at a rule
written in prose instead of in Python. The pattern-level repair is to run the admission rule over
governance text as well as over checks: name the failure the clause would have stopped, and whether
it reached a user.

Applied here: the harm the clause names is transcription — a number in a message copied into a
docstring, where it does go stale. That harm is real and stays forbidden. The other half of the
clause, forbidding a commit from counting its own changes, names no harm at all, and four rounds of
