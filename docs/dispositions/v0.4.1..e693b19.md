## Pattern

Cause 1 is the shape these records have been naming all along, arriving in the record rather than in
the code: **a claim was written from what was at hand rather than from the thing it names.** The
closure cells named symbols from the session instead of the file; this table named header fields
from a paste instead of the record. Both were checkable and neither was checked.

What is different is the repair. The symbol case was fixed by reading the file, which works only
because the file was there to read. Here the thing to read did not exist in the tree, so the repair
had to put it there. That is also, in retrospect, what the lost rounds were: no text to read.

Cause 2 needs no such repair. A record whose Source and whose reconciliation table disagree is
refutable from itself, and the check for it is reading the record whole before committing it.
