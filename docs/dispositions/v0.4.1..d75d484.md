## Pattern

**A reader whose not-read state is spelled as its clean state.** Causes 1, 2 and 14 hold it, and so
did the prior round's closed `EMPTY-SCOPE-READS-AS-CLEAN` — four units now, in three modules, all
added or reshaped inside this one range. The second input's structural cause names it for
`record_shape`; the first names it for `check_citations`; neither reaches the shape itself.

Repairing the instances will not remove it. `read_whole.whole` already established the type that
does — a read is whole or unread, with no third answer, and the whole variant is constructible only
through a full-span check — and nothing extends it from a token to a **corpus**: the set of things a
check was told to open. The pattern-level repair is that missing type: one total answer over what a
check was asked to read, what it found, and what it could not open, called from each check's entry
point, so a check that inspected nothing cannot return the value a check that inspected everything
returns. `record_shape.check` guards this by hand today and is the only one that does.

That repair is a new seam between the checks and their inputs rather than a change inside any of
them, so it is not in the table above and does not route to `plan-implementation` — it goes to
`design-boundaries`.
